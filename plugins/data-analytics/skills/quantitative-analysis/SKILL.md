# 定量分析

这里的错误答案很少是算术错误。它往往是在错误的比较对象上、或在字段名含义与数据实际含义不符的数据上，做出了正确的计算。

## 把问题框定到答案能改变决策

从决策出发。"留存情况如何"没有答案；"我们改了引导流程的那批用户，留存是否比上一批更好，好到足以值得全面推广"才有答案。

在看数据之前，先写下你预期会发现什么，以及每种情况下你会怎么做。如果所有可能的结果都指向同一个行动，这项分析就不值得做——提前知道这一点，比做这项分析更有价值。

## 先选比较对象，再选指标

几乎每个有意义的数字都是一种比较，而选择拿什么来比，比计算本身更关键。

- **与过去比**——周期要足够长，才能看穿季节性和噪声。
- **与本来会怎样比**——最强的比较，也最难构造。留出对照组、匹配细分人群、把前期趋势外推。
- **与同行或基准比**——只有定义真正一致时才有用，而通常并不一致。

**明确说出反事实。**"活动后营收上升"是拿空无作比较，这是把本就在发生的趋势归功于某项举措的最常见方式。

## 信任数据前先审问数据

看原始行。检查采集从何时开始，定义是否中途变过。检查空值率、重复项，以及测试或内部账号是否还在数据集中。检查近期数据是否仍在回填——尾部的不完整数据正是那种"突然下滑"的来源，一周后它自己就消失了。

**字段名不等于它的定义。**弄清到底是什么在写入它、在什么条件下写入，尤其是任何叫 status、type、active 或 created 的字段。

## 认清那些会得出自信错误答案的陷阱

- **聚合反转。** 如果构成比例变了，每个细分人群的比率都可能改善，而整体却在恶化。始终检查细分人群与总体是否一致；不一致时，细分人群才是真相。
- **幸存者偏差。** 只分析仍然存在的账号，回答的是关于幸存者的问题。离开的那些通常才是问题真正针对的。
- **均值回归。** 任何因极端而被选中的东西，都会自行向均值回落。针对表现最差者的干预，常被归功于此。
- **多重比较。** 按常规阈值检验二十个细分人群，总有一个会因偶然显得显著。切片之前先决定你要检验什么。
- **分母漂移。** 比率会因为分子或分母任一变化而变动。两者都要展示。
- **存在明显共同原因的关联。** 被同一季节性驱动的两样东西会完美同步，却什么也解释不了。

## 下结论前先分群，过拟合前先停手

混合数字几乎每次都会掩盖发现——一个细分人群剧烈变动，其余纹丝不动。按两三个真正可能重要的维度拆分，检查效应是普遍的还是局部的。

然后就停手。一直切片直到某处看起来有意思，必然能找到噪声，而且结果无法复现。

## 报告不确定性，而不是掩埋它

给出估计值、其区间，以及什么会改变答案。说明样本量和周期。直白说出这项分析无法确定什么——对自身局限诚实的分析，在它能确定的事情上才会被信任。

**区分数据表明了什么和你推断出了什么。** 两者都该写进报告；把它们混为一谈，就是一个看似合理的解读在第三次被重复时变成事实的方式。

## 绝不

- 做一项无论发现什么都会导致同一行动的分析。
- 报告变化却不说明它在与什么比较。
- 在细分人群与总体不一致时，从总体下结论。
- 一直切片直到某处显著，然后报告那个切片。
